\# Service Request Workflow



\## Overview



The service request workflow describes how a citizen's request moves through the system from submission to final resolution. The goal is to make each stage clear so that both citizens and municipal staff can understand what is happening.



\## Workflow Steps



\### 1. Request Submission



The citizen selects a service category, describes the problem, provides the location, and may attach a photo.



\### 2. Request Registration



The system records the request and generates a unique tracking ID.



\### 3. Initial Review



A municipal officer reviews the submitted information and checks whether the request contains enough information to be processed.



\### 4. Department Assignment



The request is sent to the department responsible for that type of issue.



\### 5. Work Assignment



The responsible officer or field team is assigned to handle the request.



\### 6. Work in Progress



The request status is updated while the problem is being investigated or repaired. Progress notes can also be added.



\### 7. Delay or Escalation



If the work cannot be completed within the expected time, a reason for the delay is recorded. Requests that remain unresolved may be escalated to a department supervisor.



\### 8. Resolution



After the work is completed, the officer adds resolution details and supporting evidence when available.



\### 9. Citizen Update



The citizen is informed that the request has been resolved and can view the final details.



\### 10. Feedback



The citizen can provide feedback about whether the issue was properly resolved.
