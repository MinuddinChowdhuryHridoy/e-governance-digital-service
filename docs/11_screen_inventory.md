\# Prototype Screen Inventory



\## Purpose



This document defines the screens that will be designed for the Week 2 prototype. The screen list is based on the functional requirements and user roles identified during Week 1.



The prototype will focus on the most important user journeys instead of trying to design every possible page of the final system.



\## Citizen Screens



\### 1. Landing / Login Screen



This screen will introduce the platform and allow existing users to log in. It will also provide access to registration and basic request-tracking options.



Main Elements:

\- System name and motto

\- Login form

\- Register option

\- Track Request option

\- Short description of the service



\### 2. Citizen Registration Screen



This screen will allow a citizen to create an account.



Main Elements:

\- Full name

\- Mobile number

\- Email address

\- Password

\- Confirm password

\- Register button



\### 3. Citizen Dashboard



This will be the main screen after citizen login.



Main Elements:

\- Report New Issue

\- Track Request

\- Recent requests

\- Request status summary

\- Notifications

\- Profile access



\### 4. Submit Service Request



This screen will allow citizens to report a municipal problem.



Main Elements:

\- Service category

\- Issue title

\- Description

\- Location

\- Optional photo upload

\- Submit button



\### 5. Request Submission Confirmation



This screen will appear after successful submission.



Main Elements:

\- Success message

\- Unique tracking ID

\- Submitted category

\- Submission date

\- Track Request button

\- Return to Dashboard button



\### 6. My Requests



This screen will show the citizen's submitted requests.



Main Elements:

\- Tracking ID

\- Issue category

\- Submission date

\- Current status

\- Responsible department

\- View Details option



\### 7. Request Details / Tracking



This screen will provide detailed information about one request.



Main Elements:

\- Tracking ID

\- Issue description

\- Location

\- Responsible department

\- Current status

\- Expected resolution time

\- Progress timeline

\- Delay reason when applicable

\- Resolution details



\### 8. Notifications



This screen will show important request updates.



Main Elements:

\- Request assignment notifications

\- Status updates

\- Delay notifications

\- Resolution notifications

\- Date and time of update



\### 9. Feedback Screen



This screen will be available after a request has been resolved.



Main Elements:

\- Service rating

\- Feedback comment

\- Submit Feedback button



\## Municipal Officer Screens



\### 10. Officer Dashboard



This screen will help municipal officers manage their assigned work.



Main Elements:

\- Assigned requests

\- Pending requests

\- In-progress requests

\- Delayed requests

\- Recently resolved requests

\- Request filters



\### 11. Officer Request Processing Screen



This screen will allow officers to review and process individual requests.



Main Elements:

\- Citizen request details

\- Category and location

\- Submitted evidence

\- Department assignment

\- Officer / field team assignment

\- Status update

\- Progress notes

\- Delay reason

\- Expected resolution time

\- Resolution details

\- Resolution evidence



\## Department Supervisor Screens



\### 12. Supervisor Dashboard



This screen will allow supervisors to monitor requests handled by their department.



Main Elements:

\- Total active requests

\- Pending requests

\- Delayed requests

\- Escalated requests

\- Completed requests

\- Officer / team workload

\- Basic performance summary



\### 13. Escalated Request Review



This screen will allow supervisors to review delayed or escalated requests.



Main Elements:

\- Request details

\- Current status

\- Delay reason

\- Assigned officer / team

\- Previous progress updates

\- Supervisor action / note



\## System Administrator Screens



\### 14. Administrator Dashboard



This screen will provide an overview of the platform.



Main Elements:

\- Total users

\- Active departments

\- Service categories

\- Total requests

\- Request status summary

\- System activity overview



\### 15. Management Screen



This screen will allow administrators to manage basic platform information.



Main Elements:

\- User and role management

\- Department management

\- Service category management

\- Permission management

\- Basic system settings



\## Prototype Priority



Not every screen needs the same level of detail.



The highest-priority screens for the high-fidelity prototype will be:



1\. Landing / Login

2\. Citizen Dashboard

3\. Submit Service Request

4\. Submission Confirmation

5\. My Requests

6\. Request Details / Tracking

7\. Feedback

8\. Officer Dashboard

9\. Officer Request Processing

10\. Supervisor Dashboard

11\. Administrator Dashboard



The remaining screens can be designed with slightly less detail while still showing their main layout and functionality.
