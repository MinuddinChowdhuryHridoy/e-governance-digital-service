\# Functional Requirements



\## Citizen Requirements



\*\*FR-01 — User Registration and Login\*\*

The system shall allow citizens to create an account and securely log in to the system.



\*\*FR-02 — Submit Service Request\*\*

The system shall allow citizens to submit a municipal service request by selecting an issue category and providing a description.



\*\*FR-03 — Provide Location\*\*

The system shall allow citizens to provide the location of the reported issue using an address or map location.



\*\*FR-04 — Upload Supporting Photo\*\*

The system shall allow citizens to attach a photo to help explain the reported problem.



\*\*FR-05 — Generate Tracking ID\*\*

The system shall generate a unique tracking ID after a service request is successfully submitted.



\*\*FR-06 — Track Request Status\*\*

The system shall allow citizens to check the current status and progress of their submitted requests.



\*\*FR-07 — View Responsible Department\*\*

The system shall show the municipal department responsible for handling the request.



\*\*FR-08 — View Expected Resolution Time\*\*

The system shall show an estimated or expected resolution time when this information is available.



\*\*FR-09 — Receive Notifications\*\*

The system shall notify citizens when important changes occur, such as request assignment, status updates, delays, or resolution.



\*\*FR-10 — View Resolution Details\*\*

The system shall allow citizens to view the final resolution details and supporting evidence when a request is completed.



\*\*FR-11 — Provide Feedback\*\*

The system shall allow citizens to provide feedback after their request has been resolved.



\*\*FR-12 — View Related Reports\*\*

The system should inform citizens when a similar issue has already been reported in the same area so that unnecessary duplicate complaints can be reduced.

\## Department Supervisor Requirements



\*\*FR-22 — View Department Requests\*\*

The system shall allow department supervisors to view all requests handled by their department.



\*\*FR-23 — Monitor Request Progress\*\*

The system shall allow supervisors to monitor pending, active, delayed, and completed requests.



\*\*FR-24 — Review Escalated Requests\*\*

The system shall allow supervisors to review requests that have been escalated because of delays or other problems.



\*\*FR-25 — Monitor Workload\*\*

The system shall allow supervisors to see the number of requests assigned to officers or field teams.



\*\*FR-26 — View Performance Reports\*\*

The system shall allow supervisors to view basic reports such as completed requests, delayed requests, and average resolution time.





\## System Administrator Requirements



\*\*FR-27 — Manage User Accounts\*\*

The system shall allow administrators to create, update, deactivate, or manage user accounts.



\*\*FR-28 — Manage User Roles\*\*

The system shall allow administrators to assign roles and permissions to citizens, officers, supervisors, and other authorized users.



\*\*FR-29 — Manage Departments\*\*

The system shall allow administrators to add, update, or remove municipal departments from the platform.



\*\*FR-30 — Manage Service Categories\*\*

The system shall allow administrators to manage service categories such as drainage, roads, waste management, and street lighting.



\*\*FR-31 — Monitor System Activity\*\*

The system shall allow administrators to monitor important system activities and user actions.



\*\*FR-32 — Manage System Settings\*\*

The system shall allow administrators to manage basic system settings related to service processing and platform operation.



\*\*FR-33 — View Overall Reports\*\*

The system shall allow administrators to view system-wide reports, including request volume, resolution status, and department-level statistics.
